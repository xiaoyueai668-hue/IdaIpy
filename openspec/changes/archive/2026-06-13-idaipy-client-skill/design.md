## 背景

Claude Code 需要一个专门技能来指导如何正确使用 IdaIpy 客户端执行 IDA 远程操作。该技能需要封装客户端 API，提供可直接调用的命令接口，处理连接管理和错误恢复。

## 目标 / 非目标

**目标：**
- 创建 `.claude/skills/idaipy/` 技能目录
- 实现 `skill.md` 主技能文件，包含完整 API 文档和使用指南
- 提供常用 IDA 操作的封装命令供 LLM 直接调用
- 包含错误处理、连接管理、超时处理等最佳实践

**非目标：**
- 不修改 IdaIpy 客户端核心代码
- 不创建新的 Python API
- 不实现IDA插件端的修改

## 决策

### 决策1：技能目录结构

**选择：** `.claude/skills/idaipy/`

**理由：** Claude Code 标准技能目录结构，便于识别和加载。

### 决策2：技能内容结构

**选择：** 包含 skill.md 主文件和 commands.py 命令封装

**理由：**
- skill.md 提供自然语言接口给 LLM
- commands.py 提供可直接调用的 Python 函数封装

### 决策3：命令封装

**选择：** 将常用操作封装为独立函数

**理由：** LLM 可直接调用这些函数而不必了解底层实现细节。

## 风险 / 权衡

- **[风险]** 技能接口与客户端 API 不同步
  - **缓解措施：** 在 CI 中添加技能与客户端 API 一致性检查
